# ✈️ AI Travel Planner — Gemini Prompting Techniques

An AI-powered travel planner built with **Python, FastAPI, and Google Gemini API** that generates personalized travel itineraries using three prompt engineering techniques.

## ✨ Features

- 🤖 Zero-Shot Prompting
- 📝 Few-Shot Prompting
- 🧠 Structured Reasoning Prompting
- 🌍 Personalized travel itineraries
- 💰 Budget and interest-based recommendations
- ⚖️ Compare all three techniques

## 🛠️ Tech Stack

- Python & FastAPI
- Google Gemini API
- HTML, CSS & JavaScript
- Uvicorn

## 🚀 Setup

**1. Clone the repository**

```bash
git clone https://github.com/Rohama789-blip/AI-Travel-Planner.git
cd ai-travel-planner
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Configure `.env`**

```env
GEMINI_API_KEY=your_gemini_api_key
```

Get your API key from [Google AI Studio](https://aistudio.google.com/app/apikey).

**4. Run the application**

```bash
uvicorn main:app --reload
```

Open http://127.0.0.1:8000 in your browser.

## 🎯 Project Goal

Demonstrate how different prompting techniques affect AI-generated travel recommendations and itinerary quality.
